# Wiki Page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a `/wiki` route that shows the full repo file tree on the left and rendered markdown on the right, with an Edit button that opens files in the existing dashboard editor.

**Architecture:** `WikiView` (already in `packages/ui`) does 90% of the work — adapt it for all-files mode and add an `onEdit` callback so the caller handles routing. A thin `WikiPage` in `apps/console` wraps `WikiView` with the StatusBar and wires the edit navigation via `preact-router`.

**Tech Stack:** Preact, `react-markdown` + `remark-gfm` + `rehype-highlight` (all already in `packages/ui`), `githubFileStore` + `layoutStore` from `@lifosy/core`, `preact-router` in `apps/console`.

## Global Constraints

- TypeScript strict mode — zero type errors
- Biome — zero lint/format warnings
- No new npm dependencies (all needed libs already installed)
- Match existing code style in each file (Preact JSX, `className` not `class` in ui package, `class` in console pages)
- Run `pnpm turbo check` and `pnpm turbo build` before marking complete
- Commit after each task

  ```tsx
      const index = wikiTree.find((i) => candidates.includes(i.path));
      if (index) {
        setActiveFile(index.path);
      } else {
        const firstMd = wikiTree.find((i) => i.type !== 'tree' && i.path.endsWith('.md'));
        if (firstMd) setActiveFile(firstMd.path);
      }
    }
  }, [wikiTree, activeFile, rootPath]);
  ```

- [ ] **Step 1: Create `WikiPage.tsx`**

  ```tsx

  import { StatusBar, WikiView } from '@lifosy/ui';
  import { route } from 'preact-router';

  export const WikiPage = () => (
    <>
      <div class="h-[calc(100vh-2rem)]">
        <WikiView
          onEdit={(path) => {
            layoutStore.navigate(path);
            route('/');
          }}
        />
      </div>
      <StatusBar
        mode="WIKI"
        onDashboardClick={() => route('/')}
  ```
